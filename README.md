# Beheading core

Первая реализация общего расчёта вероятности для Minecraft 26.1.2. Это **библиотека**, пока не устанавливаемый NeoForge-мод. Игровая регистрация зачарования, Silent Gear и loot adapters ещё не реализованы.

Сборка и тесты на Java 25: `bash scripts/build-core.sh`. Результат `build/beheading-core.jar` не помещать в mods.

`BeheadingCalculator.calculate(config, baseChance, enchantmentLevel, traitBonus, upgradeLevel)` возвращает раздельные бонусы и итоговую вероятность. Все вероятности — доли [0,1]. baseChance уже содержит Looting. По умолчанию источники объединяются через максимум; другие режимы — ADD_CAPPED, ENCHANTMENT_ONLY, GEAR_ONLY. Уровни выше диапазона ограничиваются последним настроенным tier. Отрицательные уровни, NaN, бесконечность и неверные вероятности отвергаются.

Предел бонуса не уменьшает исходную добычу. Значение cap по умолчанию 1.0 — математический предел, не утверждение о согласованном конечном балансе сборки. Все источники используют один калькулятор; он не бросает RNG и не выдаёт предметы.

[Аудит, ограничения и следующие шаги](docs/AUDIT.md). Тесты проверяют расчёт и конфигурацию, не доказывают отсутствие двойного дропа в ещё не созданном игровом адаптере.
